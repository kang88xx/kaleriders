Noto Sans KR Light (300)
========================

`kaky-sans-light.woff2` is a static 300-weight WOFF2 subset of Google Fonts’ Noto Sans KR variable font, retrieved on 2026-10-23. It preserves the character coverage of the existing regular face plus the Korean light-weight section headings.

Source: https://github.com/google/fonts/tree/main/ofl/notosanskr
License: SIL Open Font License 1.1; see OFL-NotoSansKR.txt.

The existing 400–700 faces remain unchanged.
